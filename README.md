# 나만의 데스크펫
앱 이름: app/src/main/res/values/strings.xml의 app_name 수정.
캐릭터: app/src/main/res/drawable-nodpi/pet.png를 같은 이름의 PNG로 교체.
GitHub Actions의 Build APK 실행 후 Artifacts에서 DeskPet-APK 다운로드, 압축 해제 후 APK 설치.
앱에서 시작하기 → 다른 앱 위에 표시 권한 허용 → 앱으로 돌아와 시작하기. 종료 버튼 또는 알림의 종료 사용.
인터넷 권한 및 개인정보 수집 기능 없음. 교육용 debug APK이며 실제 기기 테스트 필요. 동일 패키지의 다른 APK는 함께 설치되지 않을 수 있음. Android 8 이상 대상.
